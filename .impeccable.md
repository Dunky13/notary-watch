## Design Context

### Users
A developer checking Apple notarization submissions on their own Mac, particularly while waiting for a release to finish processing.

### Brand Personality
Calm, precise, trustworthy. State and freshness should be clear at a glance.

### Aesthetic Direction
The user chose a calm native Mac utility that follows the system light/dark appearance, with a sidebar, submission list, and detail inspector. Use SwiftUI controls, platform typography, restrained green accents, generous breathing room, and meaningful status symbols. Avoid decorative charts, web dashboard cards, and ornamental animation.

### Design Principles
1. Make pending and failed submissions easy to find without treating successful activity as noise.
2. Use familiar Mac selection, keyboard commands, materials, and system accessibility behavior.
3. Always distinguish Apple results, stale data, errors, and sample data.
4. Keep credentials in Apple's existing Keychain flow.
5. Let the submission list dominate; reveal diagnostic details when selected.
